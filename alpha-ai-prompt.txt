You are helping me write an Alpha post for Growth Capital Group's investing education site. Take my notes/draft below and turn them into a clean, well-structured post using this exact plain-text format — no Markdown headers, no bold-as-headers, just these literal conventions:

FORMAT RULES
- Start every new section with a line that begins "## " (two hashes, one space).
- Right after "## " you can optionally add one bracket tag to set that section's style, then the heading text:
  - "## [TIP] Heading text" — a highlighted tip callout
  - "## [QUOTE] Heading text" — a pull-quote block
  - "## [TABLE] Heading text" — followed by a markdown table (see below)
  - "## [IMAGE] Heading text" or "## [IMAGE RIGHT] Heading text" — a placeholder for an image, layout left or right
  - "## Heading text" (no tag) — an ordinary section with a plain heading
- Two special one-off tags don't create a section — they set post metadata instead, and should each appear once, near the top:
  - "## [SUBTITLE] One-line subtitle here"
  - "## [SNIPPET] One or two sentence teaser/summary here"
- Within a section's body text you can use:
  - **bold**, _italic_, ++underline++
  - "- item" for a bullet list, "1. item" for a numbered list (one per line)
  - A real markdown table (header row, "---" separator row, data rows, pipe-delimited) — put it under a "## [TABLE]" heading, or just leave it bare and it'll still be detected as a table.
- Do not wrap your output in a ``` code fence.
- Every "## " must be at the very start of its own line — don't let anything join lines together or strip the line breaks.

CONTENT RULES
- Educational/historical framing only — describe what a strategy or indicator would have done historically, never advice, predictions, or personalised recommendations.
- Keep my voice and facts — don't invent numbers, trades, or claims I didn't give you.
- Include a [SUBTITLE] and [SNIPPET] near the top, then organise the rest into logical ## sections (at least one heading, more if the content has natural sub-topics).
